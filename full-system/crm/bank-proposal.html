HDFC Project Proposal Process

CRM Builder Project select karein; permission, documents, bank submission aur status yahin track karein.

Process — is order mein karein

  1. 1Builder Projects se project select karein.
  2. 2Builder ki written permission lein. Builder/authorized signatory HDFC form aur declarations sign kare.
  3. 3HDFC Home Loan team se current project application form aur Gujarat document checklist lein.
  4. 4Builder ke saath listed project documents jama karein. HDFC ki current checklist final hogi.
  5. 5Letter aur signed application/documents HDFC ko submit karein. Date, contact aur reference number record karein.
  6. 6Bank ki legal/technical checking, site visit aur queries track karein; phir written decision darj karein.

CRM letter cover letter hai, HDFC ka official application form nahi. Project review/approval se har buyer ka home loan guaranteed nahi hota.

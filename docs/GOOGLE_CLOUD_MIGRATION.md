# Signature Realty CRM — Google Cloud Migration\n\nRender remains the production and rollback environment. MongoDB Atlas remains the database for this phase. Google Drive and Google Sheets integrations remain intact.\n\n## Target\n\n- Cloud Run for the Node.js CRM\n- Artifact Registry for container images\n- Secret Manager for production secrets\n- Cloud Scheduler for background synchronization\n- Cloud Storage as a future media backend behind the existing storage abstraction\n- MongoDB Atlas during the migration phase\n\n## Safety\n\nDo not delete or disable Render until Cloud Run has passed production validation. Do not migrate MongoDB data during the first Cloud Run deployment. Never put secrets in GitHub, Docker images, or source files.\n\n## Database rule\n\nCloud Run deployment alone does not fix the current snapshot-oriented MongoDB bottleneck. High-volume reads must subsequently move to indexed MongoDB collection queries with database-level pagination. Priority collections: Inventory, BuilderProjects/Projects, Leads, Requirements, Activities.\n\n## Rollback\n\nKeep Render live until Cloud Run is proven. If Cloud Run validation fails, keep DNS on Render and fix Cloud Run without touching production data.\n
